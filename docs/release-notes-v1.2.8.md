# Token用量 v1.2.8 — 最新 Codex-only、视觉简化与 GitHub 自动更新

发布日期：2026-10-06。平台：macOS Apple Silicon，macOS 13 或更高版本。本次不发布新的 Windows 安装包。

## 本次包含的最新版本内容

本次发布的是当前完整最新源码，**包含 Codex-only、视觉改动和更新功能**，不是基于旧 v1.2.7 界面仅追加一个更新模块。

- 聚焦 Codex：保留官方订阅用量、API Credits、重置机会、实时任务状态、最近完成与 Codex 会话入口。
- 移除 Claude 来源／环境检测／任务扫描；不再显示产品来源切换。
- 移除历史趋势页面、CSV 导出和清理入口；保留已有本地历史文件，不在升级中删除用户数据。
- 采用最新单层标准原生 Liquid Glass 与统一 SurfaceTone；紧凑、详细和设置模式共享明暗主题、可读底色与原生失败回退。
- 原生玻璃按 macOS 能力检测启用；macOS 13–15 使用兼容回退，不保证与 macOS 26/27 的外观一致。
- 背景亮度采样只在已有屏幕录制权限时运行；没有权限时跟随系统主题，不主动请求屏幕录制权限，不保存／上传采样图像。

## GitHub 应用内更新

- 首版仅支持 macOS Apple Silicon stable。
- 启动 30 秒后后台检查，之后每 12 小时检查；后台无更新或网络失败保持安静。
- 设置页显示版本并支持“检查更新”；发现更新后由用户明确确认安装及重启。
- 下载、签名验证和安装使用官方 Tauri Updater；更新签名绑定版本，拒绝篡改、签名不匹配及错误版本。
- 具体版本 DMG 保留首次安装与手动恢复入口；更新服务独立于用量刷新，不读取或发送 Codex 凭据。

## 安装与重要限制

**这是明确的 ad-hoc 构建，未经 Apple 公证，不等于 macOS 已信任此应用。** 本机 Gatekeeper 对检查包的评估曾返回 rejected；首次安装或更新后的启动可能被拦截，通知／屏幕录制等权限可能需要重新批准。只能使用 macOS 正常系统批准流程；不要删除安全属性、关闭 Gatekeeper 或使用绕过检查的命令。

- v1.2.7 及更早版本没有更新器：先退出旧版，将新 DMG 中的应用拖到 Applications 并从该处打开。
- 不从 DMG、App Translocation 或不可写目录执行应用内更新。
- 下载／验签失败不会开始安装；安装阶段失败不保证可靠自动回滚，需用 DMG 手动恢复。
- **真实已安装 N → N+1 升级、重启后的权限保留和核心功能回归尚未验收。** 本次发布不是完整真实升级通过的声明。
