# Token用量 v1.2.6

这是一次聚焦常驻体验和窗口管理的小版本更新。

## 新功能

- 新增“隐藏浮窗，仅保留状态栏/系统托盘”按钮。
- 隐藏主浮窗后，后台用量刷新、任务监控和通知继续运行。
- 可从 macOS 状态栏或 Windows 系统托盘菜单重新显示 Token用量浮窗。
- 详细模式和紧凑模式都支持一键隐藏。

## 其他改进

- 紧凑模式右侧操作按钮重新布局，避免遮挡任务状态和额度信息。
- 增加中英文按钮标签、悬浮提示和无障碍名称。

## 安装

macOS 用户下载 `TokenUsage_1.2.6_arm64.dmg`，将“Token用量.app”拖入 Applications 文件夹。当前安装包采用 ad-hoc 签名且未经 Apple 公证；首次启动时请在 Finder 中右键应用，选择“打开”并再次确认。

Windows 用户下载 `TokenUsage_Windows_1.2.6_x64.msi` 或 `TokenUsage_Windows_1.2.6_x64-setup.exe`。安装器未经过商业代码签名，请先使用发布的 SHA-256 文件核对完整性。

## 适用范围

- macOS 13 或更高版本，Apple Silicon；
- Windows 10 22H2 或 Windows 11，x64。
