# Token用量 v1.2.5-beta.2

这是一次聚焦背景明暗自适应体验的小型测试版更新。

## 改进

- 背景明暗的首次检测结果立即应用，避免启动时短暂出现低对比度文字。
- 背景采样间隔从 1.5 秒缩短至 150 毫秒，文字颜色能更快跟随玻璃背景的明暗变化。
- 继续使用双采样确认后续切换，避免在明暗临界区域频繁闪烁。

## 安装

1. 打开 `TokenUsage_1.2.5-beta.2_arm64.dmg`。
2. 将“Token用量.app”拖入 Applications 文件夹。
3. 当前安装包采用 ad-hoc 签名且未经 Apple 公证；首次启动时请在 Finder 中右键应用，选择“打开”并再次确认。

## 适用范围

- Apple Silicon Mac；
- macOS 13 或更高版本。
