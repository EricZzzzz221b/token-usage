# v1.2.5-beta.1 Claude Desktop 低保真设计说明

原型文件：`v1.2.5-beta.1-claude-lowfi.html`

## 设计目标

验证以下四个产品问题，不讨论最终颜色、插画或动效：

1. Codex 与 Claude 是来源维度，还是两套独立产品页面；
2. 同时运行两种来源的任务时，用户能否快速辨认；
3. Claude 额度不可可靠读取时，如何降级但仍保留任务价值；
4. 紧凑模式能否同时容纳来源、任务状态与剩余额度。

## 低保真视觉系统

- 画布：`#E9EBEF`；
- 窗口：`#F8F9FA`；
- 卡片：`#FFFFFF`；
- 主文字：`#1F2328`；
- 交互蓝：`#2764D8`；
- 正文使用系统界面字体，数据与状态使用系统等宽字体；
- 不使用品牌渐变、玻璃效果和高保真图标。

## 核心决策

- 保留“用量 / 任务”作为主导航；
- 新增 Codex、Claude 两段式来源轨道；
- 任务可以跨来源合并，但卡片必须显式显示来源；
- Claude 用量使用“共享额度”，避免被理解为仅 Desktop 消耗；
- 不可信的数据不推算百分比，改为可行动的错误说明；
- 设置按 AI 产品组织 Claude 授权、环境状态和通知。

## 原型场景

- Claude 用量：正常获得额度窗口；
- 双来源任务：Claude 等待操作，Codex 正在执行；
- 数据不可用：保留任务能力，不显示虚假百分比；
- 设置：启用集成、环境检测与通知；
- 紧凑模式：来源、任务状态、额度保持单行。

## 进入高保真前需要确认

- 任务页默认显示全部来源，还是跟随顶部来源；
- 正式版本是否可以使用 Claude 品牌图形；
- Claude provider 能稳定返回哪些额度字段；
- 等待操作是否比任务完成更高优先级。
