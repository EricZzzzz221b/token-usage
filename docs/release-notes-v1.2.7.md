# Token用量 v1.2.7

本次更新加入本地用量趋势，并改善 macOS 浮窗在不同背景下的文字对比度。

## 新功能与改进

- 新增本地用量趋势页，可查看最近 24 小时、7 天或 30 天的剩余额度变化，并切换官方额度窗口。
- 显示当前、最低和最高剩余额度；额度重置时在图表中标记。采样足够且持续消耗时，显示消耗速度及耗尽时间估算。
- 可导出当前范围的 CSV，或在确认后清除全部本地历史。历史记录采用追加写入并定期压缩清理。
- 设置页新增脱敏诊断信息查看与 JSON 导出，不包含凭据或会话内容。
- 修复 macOS 液态玻璃背景下文字与控件的自适应对比度。

历史趋势只读取本机采样数据，不上传；采样不足时会提示，预测值不代表官方额度。Claude 集成默认关闭，Claude 订阅剩余额度仍不提供估算百分比。

## 安装

macOS 13+ Apple Silicon：下载 `TokenUsage_1.2.7_arm64.dmg`，将“Token用量.app”拖入 Applications。此包采用 ad-hoc 签名，未经 Apple 公证；首次启动请在 Finder 中右键应用并选择“打开”。

Windows 10 22H2 / Windows 11 x64：下载 `TokenUsage_Windows_1.2.7_x64.msi` 或 `TokenUsage_Windows_1.2.7_x64-setup.exe`。安装器未经商业代码签名，请先核对发布页上的 SHA-256 校验文件。
